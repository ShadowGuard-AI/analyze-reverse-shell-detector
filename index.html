What is being hunted

Detects reverse shell connections by analyzing network traffic patterns and established connections, flagging suspicious shell-like activity based on communication frequency and data transfer characteristics.

That sentence is printed whole. A candid note belongs at the end of this band: the scoring explained in the next band rests on bytes alone, so the frequency part of the opening claim is named in the source but given no measure of its own there.

Next band down

The two scores, as a worked ledger

Absolute score = total_bytes / (total_bytes + 100000000)

An absolute score comes from a connection group's total bytes alone, written out above exactly as the source gives it.

Relative score = the group's share, normalized within the input file

A group is flagged when its absolute score exceeds the threshold, default 0.8, or when its relative score exceeds the threshold and its total bytes reach the minimum bytes value, default 1000000, set with --min-bytes.

The relative score alone never flags a group below that minimum.

A single large group can be flagged on its absolute score.

Deepest band

The six parameters

-hShows the help message and exits.
-iGives the path to the network traffic data file, for example CSV, or PCAP converted to CSV.
-oGives the path to save the analysis report, defaulting to reverse_shell_report.txt.
-tSets the threshold for flagging suspicious connections, defaulting to 0.8.
--min-bytesSets the minimum total bytes a connection group must reach before the relative score alone can flag it, defaulting to 1000000.
-fSets the format of the input file, only csv is supported, and it defaults to csv.
